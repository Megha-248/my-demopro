# E-Commerce Cart Website

## Overview
This project is a simple and responsive E-Commerce Cart Website developed to simulate an online shopping experience. Users can browse products, add items to the cart, update quantities, and view the total price dynamically.

## Features
- Product listing page
- Add to cart functionality
- Remove items from cart
- Update product quantity
- Dynamic total price calculation
- Responsive user interface
- Simple and user-friendly design

## Technologies Used
- HTML
- CSS
- JavaScript
